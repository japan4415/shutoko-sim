# shutoko-sim
## 概要
首都高は1周した上で1つ先で降りると1区間分の料金しか請求されません。
このプロダクトは首都高をドライブしたくなったときに自分の時間予算でできる一番コスパの良いルートを検索、提案してくれるシステムです。
## ユーザー体験
ユーザーは
- スタート地点（住所 or GPS情報）
- 最小、最大時間（分単位）
を選択する。
すると、システムはルート選択肢を地図と共に表示し、ユーザーはその中から一つを選択する。
その後、出発ボタンを押すとGoogle Mapが開き、ナビを設定できる。
## 技術
- デプロイ先
  - Cloudflare Workers
- ルート探索システム
  - WASM with Rust
    - ビルドし、R2に置いておく
- 地図
  - OpenStreetMap Japan
    - ルートの提示に使用
  - 出発の際はGoogle Map
