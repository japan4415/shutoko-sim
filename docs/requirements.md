# 機能要件とユーザー体験

[企画](product.md)を画面と状態に落とすための提案。画面の実装や完成デザインではない。

検索対象は、首都高を1周した上で入口の1区間先で降り、1区間分の料金になる経路。地図・時間・距離は実際の周回走行を示し、課金対象の1区間と取り違えない。首都高を降りた後の出発地点への帰着は今回の提案であり、原案で確定した要件ではない。

## 通常の流れ

| 段階 | ユーザーの操作 | システムの応答 |
| --- | --- | --- |
| 出発地点 | 住所を検索し候補を選ぶ、または現在地を取得 | 地図上の位置と住所を表示し確認できる |
| 時間 | 最小・最大を分で入力 | 今回の提案では一般道での帰着までを含むこと、休憩を含まないことを併記 |
| 検索 | 「ルートを探す」を押す | 準備・探索状態とキャンセルを表示 |
| 比較 | 最大3候補のカードを選ぶ | 実走行の周回経路を強調し、入口・1区間先の出口と主な通過路線を表示 |
| 詳細 | 時間内訳、周回経路、課金対象を確認 | 地図と同じ候補の詳細、推定条件、課金対象の1区間と料金額の取得状況を表示 |
| 出発 | 「出発（Google マップで確認）」を押す | 外部の経路確認画面を開く。ナビ設定は利用者が行う |

入力の暫定許容範囲は `1 ≤ 最小時間 ≤ 最大時間 ≤ 240` 分の整数。範囲内でも候補の存在は保証しない。上限は探索性能検証後に再評価する。最小・最大は総所要時間の予測値に対する条件であり、首都高上の時間だけではない。

現在地はボタン操作時に一度だけ要求する。継続追跡しない。住所の入力途中に外部検索せず、検索確定時に送る。同名住所は候補から選ばせ、最初の候補へ無断で決定しない。位置精度が悪い場合は地図上の位置を確認してもらい、住所検索に戻れる。

## 候補の表示内容

カードは総推定時間と余裕込みの計画時間、首都高・一般道の内訳、実走行距離、入口・出口、周回する路線を表示する。別項目として「課金対象: ○○入口→△△出口の1区間」を示す。「1区間の料金で首都高を約○分走る」「一般道が短い」など比較値から根拠を説明する。料金額が未算出なら円当たりの効率や最安順位を表示しない。数値スコアだけで推薦理由を置き換えない。

地図の主経路は、入口から周回して1区間先の出口へ向かう実走行の順序を示す。課金対象区間を補助表示する場合もラベルや線種で区別し、短い1区間だけを走る候補に見せない。再通過する区間は通過順序や経由地点で説明できるようにする。

初期版は「渋滞・当日の規制を反映しない推定」を表示する。料金額を取得していなければ、課金対象の表示に併せて「料金額: 未算出」と表示する。時間の余裕は統計的な到着保証ではない。経路と入口・出口の適用データの基準日、対応範囲、車両・支払い条件を参照できるようにする。

候補の地図とカードは同じ候補 ID に結び付ける。条件変更時は選択と出発リンクを失効させ、旧条件の結果で出発できないようにする。検索中の再入力では古い結果を採用しない。

## 例外と復帰

| 状態 | 応答と復帰手段 |
| --- | --- |
| 時間の逆転・小数・空欄 | 対象欄に理由を示して検索しない |
| GPS 拒否・取得失敗 | 住所検索を使える。許可要求を繰り返さない |
| 住所候補なし | 表記変更を案内し、時間入力は保持 |
| 対応地域外・接続道路なし | 対応範囲を表示。近い高速道路へ直線接続しない |
| 候補なし | 時間条件と1区間課金の周回条件を満たす候補が見つからなかったと説明し、時間を広げる操作を案内。自動変更しない |
| 入口・出口の適用データ未検証 | その組み合わせは候補にしない。通常の短距離経路を代わりに出さない |
| 探索上限到達 | 探索未完了を示し、検証済み候補だけ表示。候補なしと経路不存在を同一視しない |
| データ/WASM 不整合・通信失敗 | 再読み込みを案内。部分データで探索しない |
| 地図取得失敗 | 条件を保持して再試行。地図確認ができるまで出発を無効化 |
| 引き継げない経路 | 初期版の候補から除外。除外で0件ならその理由を表示 |
| 外部アプリがない | Google マップの Web 版を利用。開けなければ同じリンクをコピーできる |

## 操作性の要件

スマートフォンの縦画面を中心に、入力、候補、詳細の順で情報を並べる。地図だけで操作を完結させず、候補はテキストでも選べるようにする。色以外に番号・線種・選択状態で区別し、各入力にラベル、エラーに読み上げ可能な説明を付ける。キーボードで入力・候補選択・出発ができ、進捗と完了を支援技術に通知する。

Google マップには実走行の周回を維持する経由地点を渡す。入口と出口だけを渡して、周回を省いた1区間の最短経路にならないようにする。経路や所要時間が変わる可能性があるため、出発前に周回経路・入口・1区間先の出口・経由地点を確認する流れとする。走行中の継続操作は設計に含めない。

## 受け入れ条件

住所と現在地の双方で条件確定から出発リンクまで進める。全候補について次を満たすこと。

- 首都高を1周し、入口の1区間先として登録・検証した出口で降りる。
- 課金対象の1区間と、地図に示す実走行の周回経路を区別できる。
- 同一の時間判定規則を満たし、実走行の時間・距離と表示値が一致する。
- Google マップへの引き継ぎでも周回を維持できる。入口・出口だけの短距離経路への置き換わりを検出する検証を行う。

候補なし、位置拒否、圏外、地図失敗、検索キャンセルから再操作できること。外部への引き継ぎについては[検証計画](delivery.md)の実機確認を公開条件とする。
